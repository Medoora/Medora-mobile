# 📱 MEDORA Mobile App

**MEDORA Mobile** is the companion app to our web platform, bringing secure healthcare data management to your pocket. Built with Expo and React Native, it provides a seamless mobile experience for managing medical records on the go.

---

# 🎯 Features

### 📂 Medical Records on the Go
- Upload and access medical reports, prescriptions, and health documents
- Secure cloud storage with real-time sync across devices
- Organize records by categories, dates, and types

### 🔐 Privacy First
- Biometric authentication (Face ID / Fingerprint)
- Secure local storage for sensitive data
- End-to-end encryption for all health records

### 🏥 Insurance Integration
- Apply for health insurance directly from mobile
- Track application status in real-time
- Upload required documents on the spot

### 📱 Native Mobile Experience
- Offline access to critical documents
- Push notifications for updates
- Dark/Light mode support
- Responsive design for all screen sizes

# 🚀 Quick Start

## Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18 or newer)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- [iOS Simulator](https://docs.expo.dev/workflow/ios-simulator/) (for Mac users) or [Android Studio](https://docs.expo.dev/workflow/android-studio-emulator/) (for Android development)
